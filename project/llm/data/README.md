# Справочник географии

## Свободный ввод, контракт 3 — 23.09.2026

`settlements.csv.gz` — локальный индекс официального КЛАДР ФНС. Архив получен
по адресу, возвращённому [методом последней выгрузки ФИАС](https://fias.nalog.ru/WebServices/Public/GetLastDownloadFileInfo):
[base.7z от 07.07.2026](https://fias-file.nalog.ru/downloads/2026.07.07/base.7z).
Дата последней полной выгрузки ГАР в метаданных — 22.09.2026; дата КЛАДР старше.
Мы подключили именно КЛАДР, не весь свежий ГАР.

В индексе 160398 адресных объектов, 90 кодов субъектов/территорий источника,
68 обозначений типов. В том числе 94681 запись типа «д.», 34133 «с.»,
18092 «п.», 1236 «г», 916 «пгт», 5733 «х.» и 439 «ст-ца».
Это **не число всех населённых пунктов России**: есть также регионы, СНТ,
промзоны, железнодорожные объекты и другие адресные типы КЛАДР. Границы охвата
следуют исходной выгрузке.
Не проверена полнота относительно свежего ГАР и всех переименований после июля.

Сохраняются официальное название, тип, регион, район, родительский объект,
КЛАДР ID и код региона источника вакансий. Старые имена берутся из ALTNAMES,
если оба идентификатора сопоставлены с записями KLADR. Улицы/дома не включены.
Версия, распределение типов и SHA256 исходного/производного файлов находятся
в `settlements-manifest.json`. Сборщик: `python -m project.admin.build_work_places`;
нужны распакованные KLADR.DBF, SOCRBASE.DBF, ALTNAMES.DBF и dev-пакет dbfread.

ФНС описывает сведения адресного реестра как общедоступные и бесплатные:
[пояснение ФНС](https://www.nalog.gov.ru/rn60/news/activities_fts/6404159/).
Отдельный текст лицензии КЛАДР на сайте ГНИВЦ при проверке вернул HTTP 403.
Не установлена лицензия Creative Commons и не заявляется неограниченное право
перепубликации производной базы. Сохраняем источник и дату; условия внешнего
распространения требуют проверки доступного текста лицензии.

Выполняются локальные поиск по индексу, русская морфология и нечёткий поиск.
Нечёткое совпадение всегда требует выбора человека. Весь реестр не передаётся LLM.
`settlements-index.json.gz` заранее рассчитывает 83412 ключей названий и
79179 морфологических ключей; проверяется SHA256 связанной таблицы.
После пересборки данных выполнить `python -m project.admin.build_work_places_index`.
Часовые пояса наследуются из атрибутированного `cities.csv` только для известного
города либо региона с единственным указанным поясом. В неоднозначном регионе
неизвестный пояс не угадывается. Это ограничение напоминаний, не поиска вакансий.

## Профессии

`occupations.csv.gz`: 7099 названий из официально опубликованного Росстатом
«Справочника ОКПДТР 2025 года» (страница публикации 28.10.2025):
[территориальный орган Росстата](https://95.rosstat.gov.ru/folder/79471).
Точный URL XLSX, дата, хеш и способ обработки — `occupations-manifest.json`.
Сборщик `python -m project.admin.build_work_occupations` использует openpyxl.

Этот файл содержит прежнюю номенклатуру с пятизначными кодами. Его нельзя
выдавать за актуальную редакцию ОК 016-2025, вступившую в силу 01.01.2026:
[официальная карточка Росстандарта](https://protect.gost.ru/classificators/details/596bc6c9-7479-43a6-a3e0-9f6c0b988b62).
Полная актуальная редакция не подключена. Отдельная открытая лицензия на XLSX
в источнике не установлена; атрибуция сохранена. Словарь используется как
вспомогательный, а не как обязательный закрытый перечень допустимых профессий.

`vacancy-title-sample.json` добавляет 100 публичных названий из реального API
«Работы России», с идентификаторами и ссылками, без контактов. Это малая выборка,
не весь словарь портала. Код применяет морфологию и раскрытие распространённых
сокращений. Близкое название — только предложение для подтверждения.

Добавлены данные, морфология, инструкции и проверки кода. Веса LLM не обучались.

## Прежний контракт и часовые пояса

`cities.csv` — неизменённая копия [hflabs/city](https://github.com/hflabs/city),
загруженная 23.09.2026 из `https://raw.githubusercontent.com/hflabs/city/master/city.csv`.
Автор: HFLabs, сведения об адресах и КЛАДР получены авторами из DaData.
Лицензия данных: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
Копия содержит 1117 городов. Это не полный реестр всех сёл, посёлков и новых
переименований. Дата загрузки не означает актуализацию каждой записи.

Код субъекта формируется программно из первых двух цифр КЛАДР и 11 нулей.
Коды модели не принимаются. Не найденное место остаётся неподтверждённым:
бот просит уточнить название/регион, либо явно выбрать поиск по всему региону.
Часовой пояс используется для напоминания только после выбора города и
подтверждения местного времени; город поиска не считается местом пребывания.
